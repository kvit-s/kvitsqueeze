# The squeezelite build KvitSqueeze is tested against.
#
# Pinned rather than "whatever was current": the log format this app scrapes
# for engine status is not a stable interface (prd.md §7.3.4), so an engine
# upgrade is a deliberate change with a test pass behind it, not a download.
# tests/test_externalengine.cpp holds captured lines from exactly this build;
# if they stop matching after an upgrade, that test is the thing that says so.
#
# The binary is neither committed nor shipped. It is fetched at install time
# from the location in packaging/engine-manifest.txt — see that file for why
# the URL lives there and not in the installer. For a development build, put
# a copy at packaging\windows\squeezelite.exe (or point SQZ_ENGINE_EXE at
# one), or run packaging\windows\fetch-engine.ps1, and win-deploy.bat stages
# it into engine\ beside the application.

# Notes on this build, confirmed by running it against the development server:
#
#  * It is self-contained — PortAudio is linked in, so there is no DLL to ship
#    alongside it.
#  * `-a <latency>:<exclusive>` is present, which is what settled prd.md §14
#    assumption 7 and kept Backend B viable (prd.md §7.3.2).
#  * `-R` still takes the (quality)(phase)(exception) recipe ExternalEngine
#    builds; 2.0.0 adds a `q` quality and an `X` async flag, neither used.
#  * Codecs registered at startup: dsd (dsf/dff), ffmpeg (alac, wma), faad
#    (aac), vorbis (ogg), opus (ops), flac (ogf/flc), pcm (aif/pcm) and mad
#    (mp3) — which covers prd.md FR-2.1 in full.
#  * Every line ExternalEngine::applyLogLine() matches was re-captured from
#    this build and is unchanged apart from source line numbers, which none of
#    the patterns depend on. The device-open failure that FR-2.5 exists for
#    still reads `_pa_open:399 error opening device 11 - <name> [<api>] :
#    Invalid sample rate`, and `-l` still prints `  11 - <name> [<api>]`.
#
# ── What changed from the previously pinned v1.9.9-1432
#
#  * `-b`'s stock default moved from 2048:3763 to 2048:3445. ExternalEngine
#    sets the stream half deliberately and follows the stock value for the
#    output half, so kOutputBufferKb moved with it.
#  * The build options gained OGGMETA.
#  * v1.9.9-1432 was re-pinned because upstream had removed it from
#    SourceForge entirely, not because anything was wrong with it.
