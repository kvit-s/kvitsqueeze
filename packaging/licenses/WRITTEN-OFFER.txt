Notes for whoever prepares a release
------------------------------------

1.  Fill in the two blanks above. A release built without them satisfies
    nothing — the offer has to name someone who can actually be asked.

2.  Nothing here is required for a build that is never distributed. GPLv3's
    obligations attach to distribution, not to use, so a copy that stays on the
    machine that built it creates no duty to publish or to offer anything
    (prd.md §11.1). This file exists so that the first copy which *does* leave
    the machine is already correct.

3.  The offer above is the belt-and-braces form. GPLv3 §6(d) also permits
    satisfying the obligation by pointing at a network location that serves the
    corresponding source — which the GitHub URL above does — provided the
    binary is itself offered from a network location and the source stays
    available for as long as the binary does. Whether to rely on that instead
    is a decision for the release, not for this file.

4.  Any other software statically linked into the distributed
    squeezelite.exe travels under that binary's own corresponding source, which
    the offer above covers. See THIRD-PARTY-NOTICES.md for what that build
    contains.
